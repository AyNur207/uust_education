# Каталог знаний

Система обмена учебными материалами для студентов УУНиТ. HTML, CSS и JavaScript без frontend-фреймворка; Flask и SQLite на сервере. Внешний вид основан на `каталог.pdf`: Inter, фон `#f6f6fb`, фиолетовый `#6441d1`, карточки, иллюстрация, формы, десктопная и мобильная навигация.

## Запуск

Нужен Python 3.10 или новее. В папке проекта:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

Открыть **http://127.0.0.1:5000**. Если команда `python` на Windows не работает, используйте `py` или полный путь к установленному `python.exe`. Активация окружения не обязательна.

Снимки проверенного интерфейса: [главная на компьютере](docs/preview-desktop.png), [главная на телефоне](docs/preview-mobile.png).

Linux / macOS:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python app.py
```

При первом запуске автоматически создаются база `instance/catalog.sqlite3`, папка `instance/uploads` и постоянный ключ сессии `instance/session-secret`. Они исключены из Git. Повторные запуски сохраняют пользователей и материалы. Для другого порта задайте переменную окружения `PORT`.

## Что работает

- Главная, каталог, поиск по русским и английским названиям, темам и описаниям.
- Фильтры дисциплины, курса, семестра и типа; сортировка; серверная пагинация по 12 карточек с сохранением параметров.
- Регистрация, вход, выход, редактирование профиля. Пароли хранятся как хеши scrypt, формы защищены CSRF-токенами.
- Избранное для каждого пользователя, создание личных подборок, добавление и удаление материалов из подборок.
- Публикация файла или HTTP(S)-ссылки; редактирование и удаление своих материалов. PDF, PPTX, DOCX, PNG, JPG до 20 МБ; файлы хранятся под случайными именами.
- Просмотр PDF и изображений, скачивание файлов, переход по внешним ссылкам.
- Отзывы с оценкой; сообщения об ошибках сохраняются в таблице `reports`.
- Адаптивные страницы, нижняя навигация на телефоне, диалоги, состояния форм и пустые результаты.

## Данные и границы демонстрации

Первые 12 карточек, два отзыва и две подборки воспроизводят демонстрационное наполнение PDF. Их авторы не являются доступными для входа аккаунтами. Создайте собственный аккаунт через **Профиль → Зарегистрироваться**; реальные загрузки, избранное и подборки будут принадлежать ему.

Оригинальных файлов из макета нет: для демонстрационных карточек приложены **учебные PDF-примеры**, а не вымышленные оригинальные DOCX/PPTX. На карточках сохранены исходные демонстрационные метаданные и статистика; на странице материала это отмечено. Ссылка на React ведёт к официальному руководству.

На второй странице — восемь рекомендаций книг из `матан.md`, без выдуманных ссылок или полных текстов. Сам исходный файл сохранён без изменений. Поэтому количество материалов по математике отличается от макета.

Регистрация и пагинация добавлены к показанным в PDF экранам в том же стиле. Профиль показывает данные вошедшего пользователя, а не заранее выбранную Анастасию.

Уведомления пока имеют пустое состояние; рассылки, восстановление пароля и админ-панель не реализованы. Личные подборки доступны только владельцу; опубликованные материалы и загруженные файлы доступны посетителям каталога. Flask запускается локально в режиме разработки. Для публичного размещения потребуются production WSGI-сервер, HTTPS, `COOKIE_SECURE=1`, ограничение попыток входа, резервное копирование и проверка загрузок.

## Структура

```text
app.py                Маршруты, SQLite, авторизация и проверки форм
seed.py               Первоначальное наполнение
templates/            Общий шаблон и страницы Jinja2
static/css/style.css  Цвета, компоненты и адаптивная вёрстка
static/js/app.js      Диалоги, фильтры, избранное, загрузка файлов
static/fonts/         Inter и его лицензия
static/img/           Иллюстрация из PDF и иконка
static/demo/          Учебные PDF-примеры
tests/test_app.py     Интеграционные проверки с отдельной временной БД
instance/             Локальные данные, не включаются в Git
```

## Проверка

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
node --check static/js/app.js
```

Тесты используют временную базу и не затрагивают рабочие аккаунты и загрузки. Шрифт и картинки локальные; для работы интерфейса интернет не требуется.

PDF-примеры уже включены. Их необязательная повторная генерация на Windows требует PyMuPDF:

```powershell
.\.venv\Scripts\python.exe -m pip install pymupdf
.\.venv\Scripts\python.exe -m scripts.build_demo_pdfs
```
