01   Что такое массив

Массив — набор элементов одного типа, расположенных в памяти последовательно. Индексация начинается с нуля.

int a[5] = {2, 4, 6, 8, 10};
for (int i = 0; i < 5; i++) {
    cout << a[i] << " ";
}

02   Цикл for

Используй цикл, когда известно количество повторений. На каждом шаге изменяется значение счётчика.

Важно: последний индекс массива из n элементов равен n − 1.{% else %}
